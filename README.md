# Tesorería Multiorganizacional — versión funcional limpia

Versión sin datos precargados. Subir todos los archivos a la raíz de GitHub Pages.

Incluye:
- Organizaciones múltiples y selector de organización.
- Integrantes en orden alfabético y ficha individual completa.
- Cuotas obligatorias mensuales y extraordinarias separadas.
- Ingresos y egresos con estado, medio, responsable, autorización, comprobante y cuenta.
- Adjuntos de respaldo como imagen guardados localmente.
- Tesorero/a y cuentas bancarias con alternativas de bancos/tipos de cuenta.
- Saldo real disponible separado del saldo teórico pendiente.
- Informes general, integrantes, obligatorias, extraordinarias e individuales.
- Generación de PDF real con Guardar, Abrir y Compartir.
- Planilla GENERAL CSV compatible con Excel y plantilla de importación.
- Importación/exportación JSON con datos y respaldos.
- PWA y almacenamiento local IndexedDB.
