# Tesorería Pro — Semi-flat / Dual-tone / Soft-gradient

Versión PWA preparada para GitHub Pages.

## Archivos
- `index.html` — aplicación completa, con un único script interno.
- `manifest.json` — configuración PWA.
- `sw.js` — caché/offline de la aplicación.
- `icon.svg`, `icon-192.png`, `icon-512.png` — identidad visual de la Suite.

No hay carpeta `icons`, `app.js`, `patch.js` ni scripts de corrección acumulados.

## GitHub Pages
1. Subir todos los archivos a la raíz del repositorio.
2. Activar GitHub Pages desde `Settings → Pages`.
3. Seleccionar la rama y `/root`.
4. Abrir la URL publicada.
5. En Chrome/Android se podrá instalar como PWA.

## Identidad PDF
Los informes y comprobantes conservan la legibilidad de impresión y utilizan la misma paleta de Tesorería Pro: azul petróleo, turquesa, verde suave y acento coral/naranja. El encabezado utiliza un degradado suave y el contenido se mantiene claro para impresión.
