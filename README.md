# Tesorería Multiorganizacional V3

Versión preparada para GitHub Pages, sin datos precargados.

Archivos en la raíz:
- index.html
- app.js
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

Incluye:
- Organización con RUT opcional y ficha completa.
- Representantes.
- Integrantes y datos bancarios.
- Caja y cuentas bancarias con alternativas de banco.
- Cuotas mensuales, anuales y extraordinarias.
- Ingresos y egresos separados.
- Responsables y cuentas.
- Adjuntos de comprobantes como imagen/PDF.
- Saldos y resumen.
- Informes PDF descargables.
- Resumen CSV compatible con Excel.
- Exportación/importación JSON.
- PWA y funcionamiento local tras la primera carga.

Nota: los datos quedan en el navegador/dispositivo. Exporta JSON como respaldo.
