# Tesorería Pro V22 — definitiva

Aplicación limpia y reescrita sobre V21.1, conservando los formatos visuales de los PDF que fueron aprobados.

- IndexedDB estructurado por entidades
- Multi-organización
- Personas, pertenencias y relaciones
- Ficha individual y planilla general
- Segundo paso de autorización
- Movimientos, reembolsos, asignaciones masivas y comprobantes
- PDF vectorial preservado
- Respaldo/importación JSON
- PWA/offline

La carpeta `DATOS_REALES_IMPORTACION` contiene el respaldo histórico separado de la aplicación.
