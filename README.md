# Tesorería MultiOrganizacional — versión de prueba completa

PWA móvil/PC con IndexedDB. Incluye agenda maestra, múltiples organizaciones, integrantes en múltiples organizaciones, cuotas mensuales/anuales/extraordinarias con estados de participación, movimientos, respaldos, tesorero, cuentas bancarias, informes, PDF, compartir, JSON bidireccional y exportación Excel compatible.

## Importación de prueba
Use `CPA_5B_2026_IMPORTAR_CANONICO.json` desde Organizaciones → Importar JSON.
