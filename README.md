# Tesorería Pro V22 · Reimaginada

Reconstrucción visual de la V22 conservando la arquitectura funcional, IndexedDB y los documentos PDF vectoriales aprobados. La única modificación documental intencional en esta edición es la **planilla PDF**, que se genera en A4 horizontal aprovechando el ancho útil de la hoja y usando paginación cuando la cantidad de integrantes no cabe con legibilidad.

## Navegación móvil
La barra inferior se simplifica a Inicio, Personas, Ingresos, Egresos y Planillas. El resto está agrupado en **Más** para evitar iconos y etiquetas comprimidos.
